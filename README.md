Pasar Malam — a spot-the-difference game. Two near-identical hand-drawn night-market scenes side by side, 30 fair differences across 3 levels (Gerobak Sate, Bianglala, Panggung Dangdut), with a countdown timer, hints, score, and win/lose screens. All art is drawn in code — no external assets, no network requests. Play it offline in any desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — click a difference on either panel, press H for a hint, R to restart the level, 1/2/3 to switch levels. A wrong click costs 3 seconds.
